# YOUVISA Front-end Challenge

Este é o repositório para a primeira entrega do challenge YOUVISA. O objetivo é criar a base funcional do front-end da solução, aplicando conceitos essenciais de React como JSX, props e renderização de listas.

## 🚀 Sobre o Projeto

A YOUVISA é uma plataforma inovadora que visa simplificar e agilizar o processo de solicitação de vistos e passaportes. Este front-end inicial serve como a primeira interação do cliente com a plataforma, apresentando os serviços e o status de suas solicitações.

## 🛠️ Stack Utilizada

* **React:** Biblioteca para construir a interface do usuário.
* **Vite:** Ferramenta de build para um desenvolvimento front-end moderno e rápido.
* **JavaScript (ES6+):** Linguagem base para a lógica da aplicação.
* **CSS:** Estilização básica e inline para os componentes.

## 🏃‍♂️ Como Executar o Projeto

Siga os passos abaixo para rodar o projeto em seu ambiente local.

1.  **Clone o repositório:**
    ```bash
    git clone <URL-do-seu-repositorio>
    cd youvisa-frontend
    ```

2.  **Instale as dependências:**
    Certifique-se de ter o Node.js instalado. Em seguida, execute o comando abaixo no terminal.
    ```bash
    npm install
    ```

3.  **Inicie o servidor de desenvolvimento:**
    Este comando irá iniciar a aplicação em modo de desenvolvimento.
    ```bash
    npm run dev
    ```

4.  **Abra no navegador:**
    Acesse [`http://localhost:5173`](http://localhost:5173) (ou a porta indicada no seu terminal) para ver a aplicação rodando.
